# 견적 코너 가격 데이터 운영 규칙

`price-ranges.json` 하나만 코드 저장소에 둡니다. **병원 원본 수가표(xlsx/pdf)는 절대 넣지 마세요.**

---

## 1. 왜 원본을 넣으면 안 되는가

| 이유 | 설명 |
|---|---|
| 수수료 구조 노출 | 리앤장 원본에는 `정가 / 0.3 / 0.2 / 이벤트가` 컬럼이 그대로 있습니다. 수수료율이 드러납니다. |
| 해석이 매번 갈림 | 시트가 6개고 기준이 제각각입니다. 실제로 온다 가격이 30% 시트에서 잘못 들어간 적이 있습니다. |
| 추적 불가 | 원본을 직접 참조하면 어느 값이 화면에 반영됐는지 확인할 수 없습니다. |

원본은 Claude 프로젝트 파일에만 보관하고, 코드 쪽에는 **가공된 결과값만** 전달합니다.

`.gitignore`에 아래를 추가해 두세요.

```
*.xlsx
*.xls
수가표*
비용표*
```

## 2. 데이터 기준

- **근거**: 리앤장 강남점 9월 비용표 `쁘띠2` 시트(수수료 20%) + 원셀의원 정가표(2026.05)
- **대상**: 외국인 환자 적용가 (`basis: overseas_patient`)
- **VAT**: 10% 포함 기준으로 환산 완료 (`vat_included: true`)
- **단위**: 만원 (`currency_unit: 10k_KRW`)
- **제외**: 실리프팅 전 항목, 성형수술, 만료된 이벤트가, 프로모션 미끼가

### 리앤장은 반드시 20% 기준

`리엔장_강남` 시트는 수수료 30% 기준이라 환자 부담이 큽니다. **`쁘띠2` 시트만 사용합니다.**
두 시트는 `리엔장_강남` 시트의 `0.2` 컬럼 = `쁘띠2` 시트의 `정가` 로 값이 일치합니다.

### 원셀 VAT 미확인 처리

원셀 수가표에 VAT 포함/별도 표기가 없습니다. 확인 전까지는 양쪽 해석을 모두 포괄하도록 처리했습니다.

```
하한 = 원셀 표기가 x 1.0   (VAT 포함이라고 가정)
상한 = 원셀 표기가 x 1.1   (VAT 별도라고 가정)
```

확인되면 한쪽으로 고정하고 `version`을 올립니다. 범위가 평균 5~9% 좁아집니다.

## 3. A등급 / B등급

```json
{ "id": "rejuran_healer_2", "unit": "2cc", "min": 29.0, "max": 46.2, "grade": "A", "sources": 2 }
```

| 등급 | 근거 | 화면 처리 |
|---|---|---|
| **A** | 2곳 교차 확인 | 개별 가격대 표시 |
| **B** | 1곳뿐 | **개별 금액 숨김. 합산 총액에만 반영** |

B등급을 개별 표시하면 특정 병원 수가가 그대로 공개됩니다. range 방식을 택한 이유 자체가 무너지므로 프론트에서 반드시 분기 처리하세요.

```js
// 예시
const label = opt.grade === 'A'
  ? `约 ${opt.min}~${opt.max} 万韩元`
  : '咨询后告知';   // 개별 금액 비노출
// 합산에는 grade와 무관하게 min/max 모두 반영
```

---

## 4. 합산 규칙

1. 최대 **5개**까지 선택 (`max_select`)
2. 합산은 `min`끼리, `max`끼리 더함
3. 결과는 **만원 단위 반올림**해서 표시 — 소수점은 확정 금액처럼 보여 range 취지에 어긋남
4. `(max - min) / min > 0.5` 이면 `可能适用套餐优惠` 배지 노출
5. 5개를 넘기려 하면 상담 유도 문구로 전환

## 5. 필수 고지 (결과 화면)

`notice_zh` 배열 3줄을 **모두** 노출합니다. 병원별 프로모션이 매월 바뀌므로 생략하면 안 됩니다.

```
以上为外国患者适用价格区间，仅供参考。
各医院每月促销方案不同，实际费用会根据个人皮肤状态、施术范围与用量而有所差异。
最终费用以面诊后的正式报价为准。
```

버튼: `免费咨询 · 获取精准报价`

## 6. 갱신 절차

수가표는 매월 갱신됩니다. 원본이 오면 다음 순서로 처리합니다.

1. 원본은 Claude 프로젝트 파일에 업로드 (코드 저장소 아님)
2. 값 재산정 후 `price-ranges.json`만 교체
3. `version`을 갱신일로 수정
4. 이벤트가·프로모션가는 근거에서 제외 (기준일 3개월 경과분은 만료 처리)

## 7. 현재 미해결 항목

| 항목 | 내용 |
|---|---|
| 원셀 VAT 기준 | 포함/별도 확인 필요 |
| 세르프(XERF) | 두 송출처 모두 미보유. 중국 문의가 느는 항목이라 도입 여부 확인 필요 |
| 온다 | 리앤장은 만줄, 원셀은 kJ. 환산 기준이 없어 이번 데이터에서 제외 |
| 스킨보톡스 얼굴전체 | 리앤장은 cc, 원셀은 unit. 단위 불일치로 제외 |
| 리앤장 패키지 구성 | 울쎄라·써마지가에 시트팩/LED/LDM 후관리 포함. 원셀과 동일 조건인지 확인 필요 |
